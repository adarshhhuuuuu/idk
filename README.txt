I MISS YOU, BABYYY — WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open the website in your browser.

HOW TO PERSONALIZE
- Edit the text in index.html to change the message.
- Change colors and layout in style.css.
- Edit the animations and button interactions in script.js.
- The website works on phones and computers. An internet connection is only needed for the optional Google Fonts.

Note: This is a static website, so no server or installation is required.
